Я работаю Chief Data Officer в компании каршеринге Ситидрайв. Я отвечаю за 3 направления:
1. Data Platform. Сбор, хранение и обработка данных. Моделирование данных. Глоссарий метртк. Качество данных.
2. Аналитику продукта, маркетинга, операций, управлегия городов.
3. Ценообразование. Базовое ценообразование, динамическое ценообразование, персональное ценообразование.

# Орг структура
Оргстуктура моей команды выглядит следующим образом:
## Head of Data Platform
- Отдел инденеров данных (Team Lead + 3 Data-инденера)
- Отдел системного анализа данных (тим лид + 3 системных аналитика)
- Отдел BI ( тим-лид + 2 bi-специалиста)
- ща качество данных отвечает один системный аналитик.
## Head of Analytics
- Отдел продуктовой аналитики (тим лид + 3 аналитика)
- Отдел маркетинговой аналитики (тим лид + 3 аналитика)
- Отдел операционной аналитики (тим лид + 3 аналитика)
- Отдел аналитики эффективности платформы (2 аналитика)
## Head of Marketplace Efficiency and Pricing
- Команда базового ценообразования (продакт менеджер + 2 data-аналитика). Команда отвечает за базовое ценообразование, конструктор пакетов, сервисный сбор, риск-профиль. Эффективность команды будет измеряться фин-эффектов от инициатив.
- Команда динамического ценообразования (продакт менеджер + data-аналитик + data scientist)

На эти 2 команды матрично аллоцирована команда backend-инженеров состоящая из тим лида и 2-ух инженеров.
